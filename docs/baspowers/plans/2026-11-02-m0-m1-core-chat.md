# M0 + M1: Foundations and Core Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: implement this plan task-by-task with the skill named in **Execution**. Steps use checkbox (`- [ ]`) syntax.

**Execution:** baspowers:subagent-driven-development, because the clean room needs implementers whose only inputs are this plan, the spec, and the repository, and the plan is long enough that later tasks would run on a compacted context.

**Goal:** A web client that logs in to a MindRoom homeserver, lists rooms, shows the full room view and the full-screen thread view, sends Markdown, and renders MindRoom streaming, tool calls, and model badges, in the Paper, Midnight, and Studio themes.

**Architecture:** Rust crate `mindroom-core` wraps `matrix-sdk` and `matrix-sdk-ui` 0.19.1, compiled to wasm with wasm-bindgen, and emits JSON view models and list diffs. Pure mapping logic lives in `mindroom-model`, tested natively. A SolidJS app applies the diffs to stores and renders views styled only through design tokens.

**Tech Stack:** Rust 1.99 (Nix), wasm-bindgen 0.2.129, binaryen, matrix-sdk 0.19.1, SolidJS, TypeScript strict, Vite, Vitest, Playwright with system Chromium, DOMPurify, Stylelint, Bun, Tuwunel (`ghcr.io/mindroom-ai/mindroom-tuwunel`) for end-to-end tests.

**Spec:** `docs/baspowers/specs/2026-11-02-clean-room-client-design.md` (sections 3, 5, 5.5, 5.6, 6, 7 apply to every task). Visual reference: `docs/design/mockup.html`.

## Review Focus

1. A thread root whose tool trace lists 200 calls: the tool row stays one line ("Ran 200 tool calls" plus folded, ellipsized names) and expands without freezing. Test in Task 2 (`tool_calls_folds_large_trace`) and Task 9 (render test).
2. Hostile `formatted_body` (script tags, `javascript:` links, `on*` attributes, `<iframe>`, `<img>`): nothing executes or loads. Test in Task 9 sanitizer tests.
3. An agent streams 10 edits per second: only that entry's object changes and its row stays mounted. Test in Task 8 (`set keeps identity for same uniqueId`).
4. The access token is revoked from another device: the app returns to login with "Your session ended. Sign in again." and the stores are deleted. Test in Task 8 end-to-end.
5. Login input variants: `matrix.localhost` style server names, full URLs, `@user:server` in the username field with an empty homeserver, an unreachable server. Test in Task 7 (`parseLoginInput` unit tests, unreachable-server end-to-end).
