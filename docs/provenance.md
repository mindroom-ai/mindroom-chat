# Provenance

This repository has two kinds of code. The spec (`docs/baspowers/specs/2026-11-02-clean-room-client-design.md`, section 2) defines them.

## Summary

- **What:** mindroom-client is an Apache-2.0 web client for MindRoom, rebuilt clean-room from MindRoom Chat (`mindroom-ai/mindroom-chat`), a fork of the upstream client (AGPL-3.0). Bas Nijholt's requirement (2026-11-03): no line of the upstream client's code in this repository, in any commit.
- **Lanes:** Lane P files were copied from MindRoom Chat `fc3a5905` in three waves; `git blame` credited at least 95% of each text file's lines to Bas, and every other line was blanked and written fresh. Lane C is everything else, written without the source of the upstream client or MindRoom Chat, as each session reports (appendix).
- **Grant:** Bas licenses the lines he wrote in the files of waves 1 and 2 under Apache-2.0 for this project. Third-party material in those files keeps its own license (`NOTICE`), and wave 3 (images) has no recorded grant.

Its only 2 findings are in a local backup branch that main does not contain.
- **Similarity audit, 2026-11-05:** 0 clones with the upstream client; 49 with MindRoom Chat `fc3a5905`: 45 are Bas's own Lane P code, moved or repeated (mostly test setup), and 4 are trivial.
- **Clean-room rewrites:** 17 Lane P files that the ancestry audit of 2026-11-04 found derived from, or close to, upstream code were deleted unread and written again in Lane C (10 in round 1, 7 in round 2). The other files it flagged were deleted.

- Selection: `git blame -w -M -C -C` attributes at least 95% of the file's lines to Bas Nijholt (`bas@nijho.lt`). Every line attributed to anyone else was blanked when copied and listed in the wave's hole file (path, line). Lane C rewrites the blanked lines. Blame credits whoever committed a line, so it also gave Bas lines that he committed but did not write: third-party material (the Capacitor native project templates and the Gradle wrapper scripts, the T3 Code minimap port, the sign-in marks, the code block icons and the context lines of the dependency patches; `NOTICE` names each with its license) and code that he had moved out of upstream files inside MindRoom Chat (see "Ancestry audit and clean-room rewrites").
- Wave 1: `docs/provenance/portable.tsv` (path, Bas lines, blanked lines): 1580 files, 329,093 Bas lines, 655 blanked lines in `docs/provenance/holes.tsv`. The TypeScript code and tests under `src/` and `e2e/`.

The other files Bas wrote: the native shells (`ios/`, `android/`), `patches/`, locales, test fixtures and traces, `public/` assets, `scripts/`, `serve.py`, and the Docker entrypoint.
- `docs/provenance/import.txt` has one line per wave: the import commit in this repository, then the source (`mindroom-chat fc3a5905`).
- App Store fixture avatars (`scripts/fixtures/appstore/avatars/`): copied from mindroom-ai/demo at `fc39fb8a`; Bas Nijholt confirmed on 2026-11-03 that they may be included under Apache-2.0 (`NOTICE`).

- Removed from history: MindRoom Chat repository tooling (`.envrc`, `.github/`, `.claude/`, `.agents/skills`, `.gitattributes` with its merge driver, the release-tag and merge-driver scripts, the test of the release workflow) and `FORK_CHANGES.md` were imported in waves 1 and 2 and later deleted; the 2026-11-03 history rewrite removed them from every commit and their rows from the portable and dropped lists. `FORK_CHANGES.md` describes MindRoom Chat internals that were not ported, and no session may read it from any copy (see the session log for the sessions that saw parts of it before it was dropped).

## Lane C: clean code

Everything else. Each session reports in the appendix that it wrote its code without access to the source of the upstream client or MindRoom Chat beyond the Lane P files in this repository; the overlap check and the similarity audit check the code itself. Inputs are listed in the spec, section 2.

Supporting inventories, computed by the orchestrator from blame and imports only:

- `docs/provenance/seams.tsv`: modules that Lane P files import but that are not ported (path in MindRoom Chat, number of importing files, Bas share of the original, imported names). Lane C implemented them at those paths; since the restructure of 2026-11-05 they move like any Lane C module, and their Lane P importers are re-pointed with them. Rows that came from strings which only look like imports (fixtures of the import-parser tests, a comment, and two modules the e2e specs load inside the page) were removed on 2026-11-03.
- `docs/provenance/seams-dropped.tsv`: the same columns plus a reason, for seams (or single names of a seam) intentionally not built because their feature was dropped; their Lane P importers were deleted or no longer import them.
- `docs/provenance/external.tsv`: npm packages imported by Lane P files, with import counts.

`scripts/similarity-audit.sh <corpus>...` compares Lane C with each corpus: Lane P is both portable lists minus `dropped.tsv`; Lane C is every other file, tracked or untracked but not ignored, under `src/`, `scripts/` and `e2e/`, plus the root config files. A corpus that is a Git repository is compared as the files tracked at one commit (`<dir>@<commit>`, default `HEAD`, exported with `git archive`), so a checkout's untracked files and nested worktrees never count. Only the orchestrator, or a session it directs, runs it against the upstream client and MindRoom Chat, and only its report (paths and line ranges) is kept; "Similarity audit" below has the results.

## Moves

Bas's decision of 2026-11-04: the code is restructured into one layout, so files may leave the paths they were imported at. `docs/provenance/moves.tsv` lists every moved or deleted file, one row per file in the order of the moves: old path, new path (empty for a deleted file), batch. The restructure's move tool (`scripts/restructure/move.mjs`) wrote the rows. The restructure removed its tools when it was done (P4e); a later move takes them from the commit before that: `git worktree add /tmp/restructure-tools "$(git log --diff-filter=D --format=%H -1 -- scripts/restructure/move.mjs)^"`, then `node /tmp/restructure-tools/scripts/restructure/move.mjs --repo . --map <map.tsv> --batch <id>` in this checkout. `translate.sh` there carries a branch started at the old paths into the new layout, and `rename-identifiers.mjs` carries the renamed identifiers. The commit of a row is `git log --format=%h -S "$(printf '%s\t%s' <old> <new>)" -- docs/provenance/moves.tsv`.

- The portable lists, hole files, `dropped.tsv` and `seams.tsv` keep their paths. `verify-ported` reads the import commits and `check-holes` the commits that filled the blanks, where every file still sits at its listed path.
- Tools that look at the working tree carry each listed path through `moves.tsv` (`scripts/provenance-paths.cjs`): `strict-check.mjs`, the ESLint config, `similarity-audit.sh`, and `check_holes.py` without `--rev` (with `--rev`, it reads `moves.tsv` as of that revision).
- A move changes a Lane P file only in its import specifiers and the paths written in it; the move tool reports every such line. A Lane P file deleted as dead code or merged into another file gets a `dropped.tsv` row at its import-time path, and a deleted or merged seam a `seams-dropped.tsv` row.
- Batches: `clean-rewrite` (the 17 clean-room rewrites of "Ancestry audit and clean-room rewrites": 10 rows before the restructure, 7 after it), `restructure-p1-dead`, `restructure-p1-shims` and `restructure-p1-unwired` (deletions before the move), `restructure-p2` (the move itself), `restructure-p3-c<N>` (deletions, merges and renames of the cleanup chunks), `restructure-p4a` (renames left by the chunks) and `restructure-p4b-barrels` (the 51 barrels deleted and the 23 component folders they kept flattened). The P3 and P4 commit messages carry `Provenance:` lines for merges and for code moved between files.
- `merged.tsv` collects the `Provenance:` lines that merged or moved code between files: old path and its lane, new path and its lane, commit, reason (16 rows from 11 commits). In 7 rows Lane P code went into a Lane C file: 5 adapters inlined into their seam hosts and 2 test cases moved. A move does not change who wrote a line; the similarity audit can report such lines as Lane C clones of MindRoom Chat ("Similarity audit").
- The upstream overlap check reads contents, not paths; a moved file keeps its blob, and an edited one is checked like any new commit.

## Upstream overlap check

Bas's requirement of 2026-11-03: no line of Cinny's (AGPL-3.0) code in this repository, in any commit. `scripts/upstream-overlap/check.py --corpus <Cinny git repository>` (`just upstream-overlap <corpus>`, part of `just check`, skipped without a corpus) compares files with every version of every Cinny file in the corpus's history and prints only paths and line ranges of this repository. It flags:

- **Line runs:** 3 or more consecutive counted lines that each occur in Cinny. A counted line has at least 8 characters after trimming and is not trivial. Trivial lines are skipped (they neither count nor break a run): import and re-export statements (the ported files keep Cinny's module paths), JSX closing tags, JSX tags or attributes whose values are all literals (folds design tokens such as `variant="Surface"`), lines that are only a Matrix namespaced identifier (`'m.relates_to': {`), lines that are only a name or pass a prop under its own name (`eventId,`, `room={room}`; the ported code fixes these names), and comment lines. Lines that also occur in third-party code under `node_modules` are skipped as generic. `package.json` and `package-lock.json` are not checked (dependency names and versions).
- **Token runs:** 30 or more consecutive tokens of JavaScript, TypeScript or CSS (comments, imports and trivial lines left out) that occur in the same order in a Cinny file.

`--history` checks every blob of every commit. jscpd at 30 tokens against six Cinny release snapshots (`--jscpd`) was used in addition for the rewrite; its ranges are coarser.

History rewrite of 2026-11-03 (`scripts/upstream-overlap/rewrite_history.py`, git-filter-repo; the commits and their messages stay, one commit that became empty was pruned, and the history still starts at the repository's initial commit):

- Every flagged range in every blob was replaced by empty lines (imports kept, line numbers unchanged), and each blob was checked again and blanked further until it passed. `docs/provenance/history-blanked.tsv` lists every blanked line by blob. The rewrite ran three times on 2026-11-03: once over the history up to the M1 branch, once to drop a removed file's row from `portable.tsv`, and once over the fill commits below after the check learned the name-only and comment rules.
- Lane P lines blanked in the import commits are listed in `docs/provenance/holes-overlap-import.tsv` (path, line, wave); `port_files.py --verify` blanks them too, so every wave still verifies against MindRoom Chat `fc3a5905`.
- At the tip (`docs/provenance/overlap.txt`), 5,854 lines in 355 files were blank. Lane C sessions wrote them fresh without the removed code (round 1), then rewrote what still matched, with the check's line ranges for their own files as feedback (round 2). The 821 Lane P lines among them (84 files, `docs/provenance/holes-overlap.tsv`) were filled one line each; `check_holes.py --overlap --rev 54314f8` checks that.
- The 821 Lane P lines are lines that `git blame` credited to Bas but that the check found in runs shared with some version of the upstream client (3 or more lines, or 30 or more tokens). The wave 1 import commit holds 818 such blanks in 68 files (`holes-overlap-import.tsv`, which `port_files.py --verify` applies too); the two lists differ in 34 files, 32 of which changed between the import and the tip. None of these lines is in any commit now: the rewrite blanked them everywhere, each was written fresh, and the run of 2026-11-05 below finds nothing reachable from main. They showed that blame alone can credit Bas with lines that match the upstream client; the ancestry audit of 2026-11-04 then looked for such derivation file by file.
- `docs/provenance/history-rewrite-commit-map.txt` maps each commit from before the rewrite to its new commit. The old commits exist only in a private backup bundle.
- Result on 2026-11-03: 0 findings at the tip and in every blob of every commit.
- jscpd at 30 tokens against the six snapshots, at the tip after the rewrite: 0 clones in Lane C; 7 ranges in 3 Lane P files Bas wrote (`ConnectPage.tsx`, `MindroomConnectionsSettings.tsx`, `CompactRoomView.tsx`), made of folds JSX tags and attributes with literal values (exempt above) and at most 2 lines that also occur in Cinny. Their lines were not changed.
